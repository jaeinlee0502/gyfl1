# 표·본문 대조 개선 검증

2026-11-02, 공개 웹 버전. 단순한 한 줄 본문 처리로 학교형 원안지와 여러 쪽 문항정보표를 대조하지 못하던 문제를 수정했습니다.

## 바뀐 동작

- HWP 본문에서 명시적 번호·문항 끝의 배점, 바로 다음 문단의 단독 배점을 연결. 선지 안의 배점 예시를 훔쳐 붙이지 않음
- 문항 수/유형별 총점 요약 표와 실제 문항 표 구분. 서답형 제목과 별도 시험지 안내를 반영
- PDF의 번호/배점/정답 헤더 좌표로 열을 읽고, 헤더 없는 다음 쪽 및 선택형/서답형 경계를 연결. 페이지 번호·합계·비율 행은 문항으로 추출하지 않음
- 문항 수·번호 연속성·셀의 숫자 유일성을 확인하고 불명확한 값은 확정 오류로 승격하지 않음. 잘린 채점기준표 참조는 실제 정답으로 확정하지 않음
- 파일 형식 전체의 불확실성과 명시적 항목의 신뢰도를 분리. 정답 미기재 때문에 확실한 배점 대조까지 모두 확인 필요로 막지 않음
- 명시적 정답 미기재/기준표 참조/해석 실패를 구분하여 표시. 정답 대조 불가와 유형 전체의 미제공 원안지를 묶어서 안내
- 일부 유형만 있는 원안지의 소계를 전체 총점과 비교해 오류로 오판하지 않음. 유형별 합계와 전체 대조 범위를 구분
- HWP는 원본을 변경하지 않고, 메모리에서 DocInfo/BodyText만 남겨 파서에 전달. 그림·스크립트·미리보기는 읽기 대상에서 제외

## 검증

- `npm test`: **35개 통과**. 새 가상 학교형 사례, 헤더 없는 다음 쪽, 번호 유형 구분, 배점 줄바꿈, 정답 미기재 집계, 부분 총점, 모호한 숫자, 번호 공백, 잘린 참조, 별도 서답형 제목 포함
- Chromium E2E: **14개**. 기존 문서/드래그/보고서/오프라인 테스트와 가상 학교형 HWP·2쪽 PDF를 사용하는 회귀 테스트
- 가상 사례는 선택형 5문항, 별도 서답형 2문항으로 구성. 정보표의 정답과 점수도 독립적으로 만든 가상 값. 실제 첨부 자료의 문항·정답·점수 조합·파일명·개인정보를 복사하지 않음
- 사용자가 명시적으로 허용한 첨부 파일 재현은 로컬 브라우저에서만 수행. 준비 후 연결을 끊고 요청 0건, 원본 파일 해시 유지, 보고서 생성을 확인. 실제 파일·추출 결과·보고서·재현 스크립트는 공개 저장소/CI/배포물에 포함하지 않음

공개 배포 완료는 `gh-pages` push와 GitHub Pages 작업 성공을 별도로 확인합니다. 로컬/CI 검증, 실제 첨부 재현, 공개 URL 직접 HTTP 검증은 서로 구별해야 합니다. 문항 의미/정답 타당성/사실관계 검증은 포함하지 않습니다.
