- 테스트된 정적 빌드 파일은 소스와 별도의 `gh-pages` 브랜치로 게시하도록 준비했습니다. 실제 원안지/학생 정보/점검 보고서를 포함하지 않습니다.

위 설정이 활성화되고 GitHub의 배포 작업이 성공하기 전에는 예상 도메인을 실제 동작하는 공개 링크로 안내하지 않습니다. 사이트에 접속한 후 가상 예제와 XLSX 다운로드로 운영 검증을 완료해야 합니다.
