# Gemini 본인용 검토 모드 검증

2026-11-02. 실제 시험 자료나 학생 정보, 실제 API 키를 테스트/배포에 사용하지 않았습니다.

## 구현 범위

- 공개 정적 웹에 본인 Gemini Developer API 키를 입력하여 직접 Google API를 호출하는 별도 검토 모드를 추가했습니다. 기본 화면은 AI 검토이며 기존 로컬 대조도 선택할 수 있습니다. Python 데스크톱은 오프라인 동작을 유지합니다.
- PDF/이미지 원안지의 독립 풀이와 재검토를 최대 2회 호출합니다. 별도로 읽은 문항정보표의 정답은 요청에 넣지 않고 최종 응답과 PC에서 비교합니다.
- `(가),(나)` 같은 기호/자료의 대응, 복수 정답, 조건 부족, 오타 등의 후보와 짧은 풀이·인용·쪽 위치를 구조화된 JSON으로 받습니다. 원본 자동 수정/외부 검색은 하지 않습니다.
- 전송 동의, 로컬 미리보기, 진행/취소, 오류/잘림/2차 미완료 안내, 1차 의견 보존, XLSX 저장을 구현했습니다. 키와 자료를 앱 저장소에 남기지 않습니다.

## 가상 테스트

| 구분 | 검증 |
| --- | --- |
| 기존 JS 단위 35개 | 로컬 문서 추출·대조·HWP·보고서 |
| Gemini JS 단위 20개 | 요청/응답 계약, 헤더 인증, 정답표 비전송, 모델 목록 필터, 상태 코드, 취소/시간 초과, 잘림/차단/JSON 손상, 문항 수/쪽/답 검증, 2차 누락, 로컬 답 비교, 파일 매직/크기, XLSX |
| Chromium E2E 22개 | 기존 로컬 모드 14개 + AI 모드 8개: PDF/PNG 미리보기·드래그·동의·2단계·정보표 비전송·근거·XLSX·키 지우기·변경 시 무효화·할당량/잘림/2차 실패·취소·모바일 |
| Python 62개 | 기존 오프라인 데스크톱 회귀 검사 |

PDF 미리보기는 준비 상태뿐 아니라 실제 글자 픽셀도 검사합니다. 폰트가 포함되지 않은 PDF의 빈 화면 문제를 발견하여 미리보기에서 로컬 시스템 폰트/메모리 FontFace를 사용하도록 수정했습니다. 추출 worker의 네트워크 차단과 폰트 처리 설정은 유지합니다. 모든 문서의 렌더링을 보장하는 것은 아닙니다.

## 검증 한계

Gemini 테스트는 **모의 HTTP 응답**을 사용합니다. 이 환경에 Gemini API 키가 없고 Google API 도메인에 대한 환경 프록시의 CONNECT도 허용되지 않아 실제 유료 호출/모델 풀이/브라우저의 Google CORS 응답은 검증하지 못했습니다. 구현과 모의 응답 테스트를 실제 모델의 오류 탐지 정확도 검증으로 해석하면 안 됩니다. 사용자는 배포 앱에 본인 키를 입력해 가상 자료부터 시험할 수 있습니다.

가상 `samples/ai_review_fixture.pdf`, `.png`, `ai_info_fixture.xlsx`와 재생성 스크립트를 제공합니다. 개발용 가상 자료에는 의도한 결함을 설명한 문구가 있으므로 모델 능력을 평가하는 벤치마크는 아닙니다. 이전 사용자 첨부/로컬 보고서는 소스·정적 빌드·테스트·Google 전송에서 제외했습니다.
