전송할 파일 미리보기 · 원본 전체가 전송됩니다

파일에 포함된 표지·학교명·이름·숨은 텍스트 등을 자동 삭제하지 않습니다. 필요하면 먼저 제거한 복사본을 선택하세요. 미리보기 품질과 Gemini의 판독 결과는 다를 수 있습니다.

버튼 한 번에 독립 풀이와 재검토로 최대 2회 API를 호출합니다. 요금이 발생할 수 있고 자동 재시도는 하지 않습니다. Google의 데이터 처리·보관·학습 이용 조건은 이용 요금제와 약관에 따릅니다. 이 앱은 무보관을 보장하지 않습니다. 원안지 안에 이미 정답이 있으면 AI도 볼 수 있습니다.

API 키와 모델, 원안지를 준비하고 전송 동의를 선택하세요.
