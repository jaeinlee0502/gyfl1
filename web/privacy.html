Gemini AI 문항 검토

본인의 Gemini Developer API 키를 입력하고 모델 목록을 조회한 뒤 PDF·이미지를 선택합니다. 전송 동의를 체크하고 검토를 시작하면 브라우저에서 Google Gemini API로 원안지 파일 전체, 과목·학년을 보냅니다. 정답표 없이 풀이한 뒤 같은 원안지와 1차 의견을 보내 재검토합니다. 버튼 한 번에 최대 2회 생성 API를 호출하며 요금이 발생할 수 있습니다. 원안지에 정답표가 포함되어 있으면 AI도 볼 수 있습니다.

파일 선택·드롭·미리보기·키 입력만으로는 전송하지 않습니다. 모델 목록 버튼은 인증을 위해 키를 Google에 보내지만 문서는 보내지 않습니다. API 키는 이 탭의 메모리에서만 사용하며 URL·프롬프트·보고서·브라우저 저장소에 저장하지 않습니다. 공용 키나 문서 중계 서버는 없습니다. 로그인으로 접속자를 제한하는 비공개 사이트는 아닙니다.

Google의 데이터 보관·학습 이용·이용 지역·요금은 서비스/요금제/약관에 따릅니다. 이 앱은 무보관을 보장하지 않습니다. 표지·학교명·이름·숨은 텍스트를 자동 삭제하지 않습니다. 필요한 부분을 제거한 복사본을 먼저 만드세요. Google Files API의 별도 파일 저장 방식 대신 문서 전체를 매 요청에 넣는 방식을 사용합니다.

별도로 선택한 문항정보표는 네트워크 차단 작업 스레드에서 읽고, AI 풀이가 끝난 뒤 PC 안에서 정답을 비교합니다. 정보표와 그 정답은 AI 요청에 넣지 않습니다. 정보표 추출이 불확실하거나 서답형 답의 의미가 다를 수 있으면 교사가 직접 확인해야 합니다.

  • AI 입력: 실제 PDF·PNG·JPG·WEBP, 파일 10MB·PDF 30쪽·40문항, 이미지 4,000만 화소 이하. HWP는 한글에서 PDF로 저장하세요. 스캔 PDF도 보낼 수 있으나 판독 정확도를 보장하지 않습니다.
  • 기호/빈칸 누락, 발문·자료·선지 대응, 복수 정답, 조건 부족, 오타와 사실 오류 후보를 검토하도록 요청합니다. 외부 사료 검색은 하지 않습니다. AI가 틀리거나 근거·쪽 번호를 잘못 제시할 수 있습니다.
  • 결과는 모두 ‘검토 의견’입니다. ‘이상 징후 미발견’도 무오류나 출제 승인이 아닙니다. 두 번 검토해도 같은 오답을 낼 수 있습니다. AI 자체 신뢰도는 측정된 정확도가 아닙니다.
  • 잘림·차단·손상 응답은 완료로 처리하지 않습니다. 2차 실패는 1차 의견만 표시하고 미완료를 알립니다. 문항 수·번호 불일치는 범위 확인을 요청합니다. 원문을 교사가 대조하세요.
  • 자동 재시도는 없습니다. 중단 버튼은 대기를 중단하지만 이미 Google이 받은 요청의 처리·과금 취소를 보장하지 않습니다.

문서 대조 · PC에서 처리

원안지와 정보표의 번호·정답·배점만 로컬로 추출·비교합니다. 이 모드는 외부 AI를 호출하지 않고 파일명·원문·결과를 네트워크 요청에 넣지 않습니다. 문항 자체의 정답 타당성/역사 사실은 검증하지 않습니다. 파싱 작업 스레드는 fetch/XHR/WebSocket 등을 거절하며 PDF 문자맵·글꼴도 프로그램에 포함됩니다.

  • XLSX·DOCX·HWPX는 ‘문항번호 / 정답 / 배점’ 열이 있는 명시적 표를 권장합니다. 수식·병합·불명확한 값은 확인 필요입니다.
  • HWP 5.0/5.1 압축/비압축 본문, 기본 표, 명시적인 문항번호/배점을 읽습니다. 자동번호·수식·그림·복잡한 배치 전체 복원은 보장하지 않습니다. HWP 97, 암호화·DRM·배포용 HWP(ViewText)는 지원하지 않습니다.
  • PDF 정보표는 지원하는 헤더의 열 좌표와 다음 쪽·문항유형을 구분합니다. 모호한 셀은 확인 필요입니다. 구조를 판별하지 못하면 명시적 한 줄 본문을 보조 추출하며 확인 필요로 표시합니다. 로컬 대조에는 스캔 OCR이 없습니다.
  • 문항유형을 구분하여 ‘서답형 1’ 같은 번호를 사용합니다. ①/1, ①③/1,3은 같은 정답으로 비교하며 서답형 의미를 추론하지 않습니다. 두 문서에서 함께 빠진 마지막 문항은 알 수 없으므로 실제 수를 확인하세요.
  • 원안지의 정답 미기재·별도 시험지는 대조 범위를 안내합니다. 정답을 정보표에서 원안지로 복사하지 않습니다. 유형별 소계를 전체 총점과 혼동하지 않습니다.
  • 파일별 50MB, 압축 내부 100MB/5,000항목, 시트/표 20,000행, XLSX 100열, PDF 1,000쪽, HWP 1,000섹션/200,000레코드/중첩64단계/텍스트 약200만자/표100열·100,000칸 한도입니다. 45초 처리 시간 후 중단합니다.

접속·저장·지우기

처음 접속할 때 화면과 프로그램을 배포 서버에서 내려받으며 IP·접속 시각 등 일반 접속 기록이 남을 수 있습니다. 분석·광고·텔레메트리 코드는 없습니다. 문서 대조 도구의 준비 완료 후에는 연결 없이 비교할 수 있습니다. 새 접속/새로고침까지 오프라인을 보장하는 PWA는 아닙니다. Gemini 검토는 인터넷이 필요합니다.

파일과 결과를 브라우저 저장소에 저장하지 않습니다. 원본을 자동 수정하지 않고 사용자가 보고서를 내려받을 때 PC에 XLSX를 저장합니다. 보고서는 원문 근거/파일명을 포함하므로 학교 보관 규정을 지키세요. ‘지우기’는 앱의 참조/작업 스레드를 정리하며 물리적 메모리 완전 삭제를 보장하지 않습니다. AI 키도 지운 뒤 탭을 닫아 주세요.

학교가 허용한 PC·주소·브라우저를 사용하세요. 브라우저 확장 기능, OS/클라우드 폴더 동기화, 네트워크 드라이브/다운로드 경로까지 이 앱이 통제하지는 못합니다. 최신 데스크톱 Edge/Chrome을 권장합니다.
