문서는 선생님의 브라우저 안에서 처리합니다.

이 프로그램에는 파일 업로드 API, 문서 저장 서버, 외부 AI API, 분석·텔레메트리 코드가 없습니다. 브라우저의 파일 선택 또는 드래그 앤 드롭으로 읽고 웹 작업 스레드에서 추출·대조합니다. 파일과 결과를 브라우저 저장소에도 저장하지 않습니다. 직접 보고서 내려받기를 선택할 때만 PC에 XLSX를 저장합니다.

접속과 점검의 차이

처음 접속할 때 화면·프로그램 파일을 배포 서버에서 내려받습니다. 배포 서버에는 일반적인 접속 기록(IP·접속 시각 등)이 남을 수 있습니다. 시험 파일명·원문·점검 결과는 요청에 넣지 않습니다. 준비 완료 후에는 네트워크를 끊어도 점검할 수 있습니다. 새로고침하거나 새로 접속할 때는 인터넷이 필요합니다. 설치형 오프라인 앱처럼 새 접속까지 보장하는 서비스 워커는 제공하지 않습니다.

지원 범위

HWP 5.0/5.1 파일을 서버 변환 없이 직접 읽습니다. 압축/비압축 본문과 기본 표를 추출하되 자동번호·수식·그림·복잡한 배치의 복원을 보장하지 않아 HWP 추출값은 항상 확인 필요로 표시합니다. 암호화·DRM·배포용 HWP(ViewText)와 HWP 97/3.x는 지원하지 않으며, 권한이 있는 원본이나 HWPX 복사본을 사용해야 합니다. 미리보기만 있는 파일을 본문으로 대체하지 않습니다.

  • XLSX / DOCX / HWPX: ‘문항번호 / 정답 / 배점’ 열이 있는 명시적인 표를 권장합니다. 각 파일 50MB, 압축 내부 100MB/5,000개 항목, 시트/표 20,000행, XLSX 100열 이내입니다.
  • 문항유형 열은 ‘객관식 / 서답형’ 등을 지원하며 ‘서답형 1’ 형태의 번호도 사용할 수 있습니다. 서로 다른 유형이 같은 번호를 쓰면 유형을 반드시 구분하세요.
  • 정답 ①과 1은 같은 값으로, ①③과 1,3은 같은 복수 정답으로 대조합니다. 서답형 의미/동의어는 추론하지 않습니다. 배점은 숫자/2.5점 같은 형식만 지원합니다.
  • PDF는 텍스트가 있는 한 줄 문항을 보조 지원합니다. 예: 1. 가상 문항 [정답: ①] [배점: 20점]. 본문 추출은 항상 ‘확인 필요’입니다. PDF 표/다단 복원·OCR은 제공하지 않습니다. 암호화/손상 파일은 지원하지 않습니다.
  • 수식·병합·해석 실패·숨긴 시트 등 불확실한 추출은 확인을 요청합니다. DOCX/HWPX 복잡한 배치·머리말·그림·수식은 전체 복원을 보장하지 않습니다.
  • 두 문서에서 동시에 빠진 마지막 문항은 알 수 없습니다. 단일 숫자 번호의 중간 공백은 확인을 요청하되 소문항의 연속성은 자동 추정하지 않습니다. 원문의 문항 수를 미리보기와 대조하세요.
  • 문항 내용, 역사적 사실, 정답의 타당성, AI 검증은 포함하지 않습니다. 정상 판정도 문서 전체가 정확하거나 출제 승인되었다는 뜻은 아닙니다.

사용 시 확인할 사항

원안지와 문항정보표 영역에 파일을 한 개씩 놓으세요. 여러 파일·폴더·미지원 파일·영역 밖 드롭은 거절하고 기존 선택을 유지합니다. 점검 중에는 파일을 교체할 수 없습니다. HWP 본문은 최대 1,000섹션/200,000레코드/중첩 64단계/텍스트 약 200만자/표 100열·100,000칸을 지원 한도로 둡니다.

학교에서 허용한 로컬 PC, 브라우저와 배포 주소를 사용하세요. 파일 선택 창에서 네트워크 드라이브/클라우드 동기화 폴더를 고르는지 여부와 다운로드 저장 위치는 브라우저/운영체제가 관리하므로 이 웹 앱이 강제 통제하지 못합니다. 브라우저 확장 기능, 배포 서버가 임의로 삽입한 스크립트, 운영체제의 동기화까지 감시하는 도구는 아닙니다.

‘선택·결과 지우기’는 앱의 참조와 작업 스레드를 정리합니다. 메모리의 물리적인 완전 삭제를 보장하는 기능은 아닙니다. 사용을 마치면 탭을 닫아 주세요. 보고서는 파일명과 원문 근거를 포함하므로 학교의 보관 규정을 지켜 주세요.

최신 데스크톱 Edge/Chrome을 권장합니다. 별도 회원가입이나 Python 설치는 필요 없습니다.
